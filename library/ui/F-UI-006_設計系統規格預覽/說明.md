# 設計系統規格預覽

## 這個功能幫我做什麼

**19 個各自獨立、雙擊就能開的 HTML 頁面**，每一頁展示設計系統的一個面向。

不是文件、不是 Figma、不是 Storybook——**就是可以直接開的網頁**，每頁 2–5 KB。

| 類別 | 頁面 |
|---|---|
| 色彩 | `colors-neutrals` · `colors-accent-success` · `colors-semantic-warn-danger` · `colors-chart-palette` |
| 字體 | `typography-scale` · `typography-specimen` |
| 間距 | `spacing-scale` · `spacing-radii-shadows` |
| 元件 | `components-buttons` · `cards-kpi` · `table` · `form-fields` · `filter-chips` · `modal` · `search` · `header-nav` · `status-banners` · `action-strip` |
| 徽章 | `badges-grade-status` |

外加一支共用的 `colors_and_type.css`（放在設計系統根目錄，不在 `preview/` 裡）。

> **沒有目錄頁。** `preview/` 底下就是 19 個平鋪的檔案，靠檔名前綴分組——這是刻意的，
> 少一個要維護的索引檔，而且檔案總管本身就是目錄。

## 為什麼這比 Storybook 有用（在這個情境）

| | Storybook | 這個做法 |
|---|---|---|
| 要不要裝東西 | npm 一整套 | **不用，雙擊就開** |
| 交接給非工程師 | 教他跑 dev server | 把資料夾複製給他 |
| 跨專案共用 | 綁前端框架 | **純 HTML，任何專案都能看** |
| 五年後還打得開嗎 | 相依早就爛了 | **會** |
| 互動測試 | ✅ | ❌ |

**這是「規格書」不是「元件庫」。** 它回答「這個系統長什麼樣」，不回答「怎麼寫這個元件」。

對一個一個人維護、要交接給別人、跨多個技術線（Flask+Jinja、React、Streamlit）的專案來說，
**這個形式的存活率遠高於任何需要 build step 的方案**。

## 三個設計決定

### 1. 一頁一主題，不做成一頁全部

19 個小檔案而不是一個大檔案。要看色票就開色票那頁——不用捲。
而且**改一個主題不會動到其他頁**，衝突機率是零。

### 2. 每頁自帶樣式，只共用 token

```
colors_and_type.css     ← 共用的 CSS 變數
components-buttons.html ← 自己的版面 + 引用上面的變數
```

**token 共用、版面各自獨立。** 這樣任何一頁單獨拿出去也還是完整的。

### 3. 檔名就是分類

`colors-` / `typography-` / `spacing-` / `components-` / `badges-` 五個前綴。
不用資料夾、不用索引，看檔名就知道在哪一類，排序也自然分好組。

## 與資料庫裡其他 UI 條目的關係

```
F-UI-006（本條）  規格書 — 這個系統長什麼樣
      ↓ 定義了 token
F-UI-001          暖色設計 token — 實際可用的 CSS 變數與元件樣式
      ↓ 被使用於
F-UI-005 抽屜式編輯頁 · F-UI-002 命令面板 · F-UI-003 官網版型
```

**先看 F-UI-006 知道長相，再拿 F-UI-001 的 token 開工。**

## 移植點

| 位置 | 要改的 |
|---|---|
| `colors_and_type.css` | 換成你的 token（與 `F-UI-001` 是同一套的另一個投影） |
| 各頁的展示內容 | 換成你的色階、字級、元件 |
| `index.html` | 目錄，跟著改 |

**可以整段照抄的**：**整個做法本身**——一頁一主題、檔名分類、token 共用版面獨立、純 HTML 零相依。
這比抄任何一頁的內容都有價值。

## 已知限制

- **只有靜態展示，沒有互動狀態。** hover / focus / disabled 這些要在頁面上手動排出來，不會自動展示。
- 沒有自動與實際程式碼同步。**規格書改了、程式碼沒改（或反過來）不會有人告訴你。**
  這是這個做法的主要代價——換來的是零相依與長期存活。
- 沒有暗色模式頁面。

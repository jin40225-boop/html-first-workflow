# 課程互動教學 HTML

## 這個功能幫我做什麼

把一堂「操作型」課程（講師現場示範怎麼點、怎麼貼、怎麼部署）做成**學生帶回家也能自己重看、自己照做**的單檔離線 HTML：

- 上方是**章節分頁**，下方一排**步驟節點**，點哪一步就直接跳到那一步，畫面狀態一定正確。
- 可以停在某一步慢慢看、隨意跳，也可以按播放**照上課順序**自動演示（游標移動、打字、點按、對話框、部署流程）。
- 模擬的是學生真的會用到的畫面（Gemini、Gem 管理、Canvas、Chrome 線上應用程式商店、Google 文件、Apps Script、試算表、AppSheet 編輯器與手機預覽）。
- 頂部「📋 範本與程式碼」打開一份**學生公版**：每段 HTML、Apps Script、AppSheet 公式都能一鍵複製，照步驟貼上就真的能跑；AppSheet 用的試算表範本可直接下載 .xlsx。
- 全頁淡浮水印＋角落署名＋頁尾智慧財產聲明，標明講師是作者。

## 技術線

```
src/index.html（頂部標題＋講師署名＋範本按鈕＋模式切換；#chaps 章節膠囊；#nodes 步驟節點；
              擬真瀏覽器外殼〔分頁列、書籤列、擴充功能彈窗、#bview〕＋側欄對話／手機面板；
              覆蓋說明頁；字幕列；浮水印；<section class="kit"> 學生公版；大綱；頁尾聲明）
src/app.js
  ├ 內容常數：提示詞、各版回饋、Gem 指令、學生用 HTML／Apps Script 原文（GS_GET、GS_WC、HTML_WC、slotHtml）
  ├ seed()：虛構學員名單、對話、Apps Script 專案、試算表、AppSheet 表格 → 狀態 S
  ├ 各畫面 renderer：vGemini / vGemEdit / vCws / vDocs / vGas＋gasDlg / vSheet / vApps＋asPanel / asPhone …
  ├ ACT{}：所有按鈕的動作（data-act 事件委派）——導覽與自由操作共用
  ├ asCheck() 驗公式／asCalc() 算距離與補助：學生在模擬器裡填錯公式會被指出來
  ├ KIT[]＋renderKit()：學生公版清單（一鍵複製、xlsx 下載）
  ├ CH[] 章節、STEPS[]：{ ch, fn, t 字幕, tip 常見錯誤, run: async 動作序列 }，本案 11 章 85 步
  └ goto(i)：先 FAST 重播 0..i-1，再正常播第 i 步；網址 #s=N 直達第 N 步
src/app.css、app2.css（擬真畫面與外殼樣式）＋ ds-tokens.css、ds-components.css（F-UI-031，未收在本條）
src/build.py → 內嵌 CSS／JS；{{IMG:路徑}} 轉 data URI、{{B64:路徑}} 轉 base64（xlsx 範本）、{{OUTLINE}} 由 STEPS 自動產大綱
             → dist/<課名>_互動教學_<版號>.html
appsheet_template.xlsx（AppSheet 章用的空白試算表範本，欄位已建好、無資料）
```

## 核心手法

1. **引擎沿用 F-UI-032**：導覽與自由操作走同一組 ACT 動作；跳步驟靠 FAST 重播而不是快照；→／右鍵兩段式（第一下讓這步播完，第二下下一步）；觀眾一點畫面就 `userTook()` 讓位。
2. **步驟節點＝目錄**：每一步一顆節點，章節分頁只是節點的分組；`#s=N` 深連結讓講義、投影片、訊息可以直接指到某一步。
3. **字幕＋常見錯誤**：每步除了字幕 `t`，另有 `tip` 小卡寫「最常卡在哪」，放在不擋按鈕的角落（實測曾擋住 SAVE 與部署鈕，已移到左下）。
4. **畫面裡的程式碼就是學生要貼的程式碼**：模擬器在 Apps Script 編輯器裡「貼上」的內容，與學生公版裡一鍵複製的是同一個常數；拉霸機 HTML 由 `slotHtml()` 用模擬器自己的 `mountSlot.toString()` 組出完整獨立檔，示範與成品不會分岔。
5. **模擬器會驗收學生填的東西**：AppSheet 章的 `asCheck()` 檢查公式（例如 `ROUND` 只收一個參數、`LATLONG` 不加引號），`asCalc()` 依公式真的算出里程與補助；Apps Script 的文字雲沒換成試算表 ID 就不讓它跑。
6. **擬真到標籤字一字不差**：按鈕、選項、對話框文字照真平台實測抄（例如「建立新版本」「所有人」「網頁應用程式要求您授予資料存取權」），學生回到真畫面才找得到。
7. **作者標示**：SVG 斜向浮水印（不透明度約 .045，淡到不干擾）、左下角署名徽章、頁尾智慧財產聲明；浮水印與徽章都避開互動按鈕。

## 移植點

> **技能內快照只收本說明，不收程式碼**：原碼含講師署名與真實地名，技能會公開發佈。程式碼正本在本機軟體資料庫 `功能庫/介面元件/課程互動教學HTML/code/`；別台電腦沒有正本時，用 `assets/course-tutorial-template.html` 骨架照本說明重建。

- `code/` 已攤平成單層；每檔原本在專案裡的位置見 `來源.json` 的「原始相對路徑」，還原時照它放回（`appsheet_template.xlsx` 放回 `src/assets/files/`）。
- **內容**：`CH`、`STEPS`、各內容常數（提示詞、學生用程式碼）、`seed()` 虛構資料、`KIT` 公版清單、`RECAP` 收尾重點、`index.html` 的課名與講師署名、浮水印文字。
- **擬真畫面**：要教別的平台就換對應 renderer 與 ACT；`tap / point / typeIn / spot` 與 `goto` 不用改。`q()` 同時接受 `data-t` 代號與 CSS 選擇器。
- **樣式與圖**：放回 F-UI-031 的 `ds-tokens.css`、`ds-components.css`；人物取 F-UI-030；本課的水彩貼圖與示範截圖未收，換課要重新準備（新圖走 art-commission-pipeline）。
- **打包**：`python build.py v1` → `dist/`；單檔約 4–5 MB（圖片內嵌）。CJK 長路徑的 `file://` 在部分內嵌瀏覽器打不開，交付給學生時改用英文檔名或從一般 Edge／Chrome 開。

## 相依套件

- 無（原生 JS／CSS）；`build.py` 只用 Python 標準庫。
- 觀看端：Edge 或 Chrome。

## 已知限制

- 模擬畫面是某一天的真平台長相；Google 改版（例如 2026/11/17 起 Gem 改名「技能」）後標籤要重新實測對齊。
- 狀態只在記憶體，重新整理回到初始；學生在模擬器裡填的內容不保存。
- AppSheet 章的公式是負責人先前在真 AppSheet 用過的版本，本次未在真 AppSheet 重跑；Apps Script 兩支（拉霸機、文字雲）有實跑。
- 尚未實際發給學生使用；學員回饋到後要更新本條狀態。

## 驗證證據

- 2026-10-25：85 步逐步實播（從第 0 步依序 goto 到最後一步）零錯誤；模擬狀態檢查：文字雲寫入 8 列且畫出、AppSheet 新增一筆紀錄算出補助 400 元。

- 真 Google Apps Script 實測（負責人核可在他帳號建測試專案）：拉霸機網頁應用程式部署後網址可轉、轉出名字；文字雲試算表＋綁定專案第一次失敗（`getActiveSpreadsheet()` 在網頁應用程式為 null），改 `openById` 後部署 v2、重新整理後寫入 3 列並畫出文字雲。實測後把模擬器的對話框文字、授權出現的時機、版本選項名稱都改成與真平台一致。
- 學生公版擷取出的 HTML 與 `.gs` 原文經 SHA-256 比對，與實測時貼進真編輯器的內容一致。

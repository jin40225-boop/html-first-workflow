# 課程互動教學 HTML

## 這個功能幫我做什麼

把一堂「操作型」課程（講師現場示範怎麼點、怎麼貼、怎麼部署）做成**學生帶回家也能自己重看、自己照做**的單檔離線 HTML：

- 上方是**章節分頁**，下方一排**步驟節點**；點哪一步就直接跳到那一步，畫面狀態一定正確。
- **每章第一步是章節介紹**：大字寫章名、這章學的 AI 知能、用途、這一章會做哪幾步。
- **每章最後一步是本章小結**：每一步都是按鈕，可以點回去重看，還有「下一章 ▶」。自動播放會停在小結，等學員按下一章。
- 可以停在某一步慢慢看、隨意跳，也可以按播放**照上課順序**自動演示（游標移動、打字、點按、對話框、部署流程）。
- 模擬的是學生真的會用到的畫面：Gemini、Gem 管理、Canvas、Chrome 線上應用程式商店、Google 文件、Apps Script、試算表、AppSheet 編輯器與手機預覽。
- **示範畫面佔滿舞台**：瀏覽器外框只在介紹擴充功能的章節出現；說明是浮在畫面上的半透明卡片，會自動避開正在操作的地方。
- **組裝說明式的零件卡**：用得到程式碼、公式、範本的那一步，說明卡出現「🧩 這一步的零件」，可以一鍵複製或下載。全部零件另有一頁「📋 範本與程式碼」，兩邊是同一份。
- **「⚠ 一定要」統一標註**：清空再貼上、按儲存、程式碼先執行一次、選網頁應用程式、管理部署作業 → 鉛筆 → 建立新版本、AppSheet 三層儲存。目標會放大、放慢，樣式全課一致。
- 全頁淡浮水印＋角落署名＋頁尾智慧財產聲明，標明講師是作者。

## 核心手法

1. **引擎沿用 F-UI-032**：導覽與自由操作走同一組 ACT；跳步驟靠 FAST 重播；→／右鍵兩段式；觀眾一點畫面就讓位。
2. **畫面優先**：拿掉側欄與常駐的瀏覽器外框；說明卡浮在畫面上。擺放時避開這一步碰過的所有地方（眼前目標加權），沒擋到就不移動；真的避不開時，先試寬而矮的卡，再把提醒與零件收成一行，最後才變半透明（擋到一成以上）。
3. **零件跟著步驟走**：`PARTS` 把步驟對到 `KIT` 零件；畫面裡貼上的、說明卡複製的、範本頁複製的，都是同一個常數。
4. **章節節奏**：章節介紹與小結由 `CHINFO` 在執行時產生，不必手寫；小結的步驟按鈕不會觸發自由操作。
5. **一定要的步驟統一演法**：`must()` 先放大目標、再上橘色框與標籤、停 1.6～2.6 秒；下拉選單用 `pickOpt()` 慢動作展開；程式碼只標那一行（`lineEl`），不放大整個編輯區。
6. **擬真到標籤字一字不差**：按鈕、選項、對話框文字照真平台實測抄。
7. **示範不碰使用者的電腦**：導覽代按不寫系統剪貼簿；不自動下載。

## 移植點

> **技能內快照只收本說明，不收程式碼**：原碼含講師署名與真實地名，技能會公開發佈。程式碼正本在本機軟體資料庫 `功能庫/介面元件/課程互動教學HTML/code/`；別台電腦沒有正本時，用 `assets/course-tutorial-template.html` 骨架照本說明重建。

- `code/` 已攤平成單層；位置見 `來源.json` 的「原始相對路徑」（`appsheet_template.xlsx` 放回 `src/assets/files/`）。
- **內容**：`CH`、`STEPS`、`CHINFO`、`PARTS`、`KIT`、內容常數、`seed()`、`RECAP`、`index.html` 的課名與講師署名、浮水印文字。
- **擬真畫面**：要教別的平台就換 renderer 與 ACT；引擎函式不用改。`applyChrome()` 決定哪一章顯示瀏覽器外框。
- **樣式與圖**：放回 F-UI-031 的 `ds-*.css`；人物取 F-UI-030；本課的水彩貼圖與示範截圖未收。
- **打包**：`python build.py v2` → `dist/`；單檔約 4.8 MB。給學生時請他們用 Edge／Chrome 開。
- 舊版（v1：有聊天室側欄、底部字幕條）封存在 `_歷程/版本封存/course-tutorial-v1-95773301f346/`；聊天室元件另收為 F-UI-035。

## 已知限制

- 模擬畫面是某一天的真平台長相；Google 改版後標籤要重新對。
- 狀態只在記憶體，重新整理回到初始。
- 全程自動播放約 25 分鐘；學員可用 → 加速。
- 「開場」「收尾」沒有章節介紹與小結（開場最後一步會停）。
- AppSheet 公式未在真 AppSheet 重跑；Apps Script 兩支有實跑。尚未實際發給學生。

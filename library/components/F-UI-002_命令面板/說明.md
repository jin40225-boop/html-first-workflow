# 命令面板

## 這個功能幫我做什麼

按 `Ctrl+K` 跳出一個搜尋框，打字就能：**找資料、跳頁、執行動作**。不用在選單裡翻。

對每天要開幾十次同樣幾個頁面的人來說，這是省時間最有效的單一元件。

## 技術線

```
Ctrl/Cmd + K → 開啟（攔截瀏覽器預設行為）
  ↓  輸入，200ms 防抖
  ├─ 「>」開頭 → 只顯示動作，不查資料
  ├─ 少於 2 字 → 清空
  └─ 否則 → fetch /api/search
  ↓  合成三組結果
     ① 資料（動態查詢）
     ② 前往（導覽項目，依角色過濾）
     ③ 動作（新增、重新偵測、開啟資料夾…）
  ↓  ↑↓ 跨組循環移動 · Enter 執行 · Esc 關閉
Alt+1 ~ Alt+7 → 直接跳頁，不用開面板
```

## 五個踩過坑才有的細節

**這一段是這個條目的主要價值。** 命令面板本身不難寫，難的是這些坑。

### 1. 狀態變數不能叫 `open`

```js
// ✗ open: false
// ○ isOpen: false
```

原始碼註解寫明：`open` 會與瀏覽器內建的 `window.open` 撞名，
Alpine 在 with-scope 求值時可能解析到那個函式（函式是 truthy），**導致面板永遠判定為開啟**。

這種 bug 極難查——程式碼看起來完全正確。

### 2. 搜尋要用序號防競態

```js
const seq = ++this._seq;
const res = await fetch(...);
if (seq !== this._seq) return;      // ← 已經有更新的查詢了，丟棄這次結果
```

打字快的時候，先送出的請求可能後回來，**結果會覆蓋掉正確的**。
遞增序號、回來時比對，不是最新的就丟棄。

### 3. Alt+數字要用實體鍵碼

```js
if (e.altKey && e.code === 'Digit3') { ... }    // ✓ 用 e.code
// if (e.altKey && e.key === '3')               // ✗ 不同鍵盤佈局會產生特殊字元
```

`e.key` 在某些鍵盤佈局下 `Alt+3` 會變成 `#` 或其他符號。`e.code` 認的是實體按鍵位置。

### 4. 不要完全依賴框架

```html
<!-- 預設 display:none，不靠 Alpine 的 x-show -->
<div id="command-palette" style="display:none" x-data="commandPalette()">
```

```js
// Esc 關閉用全域 document.addEventListener，不用 Alpine 的 @keydown
```

理由寫在註解裡：**萬一框架載入失敗或初始化出錯，面板不會卡在畫面上擋住操作。**
用 `x-show` 的話，Alpine 沒起來就等於一個永遠打不開也關不掉的黑幕。

### 5. 前端角色判斷要有單一來源

```js
const role = document.body.getAttribute('data-bg');   // "admin" | "worker"
```

導覽項目要依角色過濾。**這個屬性是前端唯一的角色來源**，同時也決定頁面底色。
不要在多個地方各自判斷角色，會不一致。

## 移植點

`code/command_palette.html` — 版面與樣式，**要重寫**（綁著專案的 CSS 變數）。

`code/warm-theme.js` — 這支 16.8 KB，命令面板只是其中一部分：

| 位置 | 內容 |
|---|---|
| `window.commandPalette()` 工廠函式 | **本條目的主體**，可整段抄 |
| `openDrawer` / `closeDrawer` | 抽屜開合含完整 focus trap（另一個可用元件） |
| `countUp` / `bentoPulse` / `revealWorkerBars` | 數字與長條動畫 |
| `chartTheme` / `chartAnim` | 圖表配色與動畫設定 |
| `prefersReducedMotion()` | 減少動態偏好偵測 |

**每一個動畫 API 都各自檢查 `prefersReducedMotion()`**——這是無障礙的正確做法，值得照抄。

要改的：搜尋端點路徑、導覽項目清單、動作清單、角色屬性名稱。

## 相依套件

```
Alpine.js（可替換——核心邏輯是純 JS，換成任何框架或 vanilla 都行）
```

**載入順序有陷阱**：定義工廠函式的那支 JS 必須排在 Alpine **之前**。
Alpine v3 在自己的 defer script 執行時就啟動，不會等後面的 defer script——工廠函式還沒定義的話 `x-data` 會綁成空物件，整個面板靜默失效。

## 已知限制

- 搜尋結果上限 8 筆，沒有分頁或「看更多」。
- 沒有使用紀錄或常用排序。用久了應該把常開的排前面。
- 快捷鍵寫死，不可設定。

# 課程互動教學 HTML（軌道 A 的變體）

> 把一堂「操作型」課程做成學生帶回家也能自己重看、自己照做的單檔離線 HTML。
> 骨架：`assets/course-tutorial-template.html`
> 完整實作（11 章 85 步、Gemini／Apps Script／試算表／AppSheet 擬真畫面）：說明在 `library/components/F-UI-034_課程互動教學HTML/說明.md`；程式碼只在本機軟體資料庫 F-UI-034（含講師署名，不隨技能公開）
> 引擎源頭：軟體資料庫 F-UI-032（給委託方看的功能示範）

## 什麼時候用

- 使用者在準備**課程、講義、教學示範、上課操作步驟、工作坊**，而課程內容是「教別人在某個軟體或平台上一步一步做出東西」。
- 手上有：講課逐字稿、上課截圖、示範對話紀錄、要學生貼的程式碼或公式。
- 不適用：只要投影片（用簡報類技能）、現場即時互動投票（用 `deck-site-factory`）、給委託方看的軟體提案（用 `client-demo.md`／F-UI-032）。

## 和客戶展示頁差在哪

| | 客戶展示頁 | 課程互動教學 |
|---|---|---|
| 觀眾 | 委託方、長官 | 學生（會照著做） |
| 目標 | 建立信心 | **學生回到真平台照做會成功** |
| 擬真的標準 | 看起來像 | 按鈕、選項、對話框文字**一字不差**，學生才找得到 |
| 程式碼 | 可以是示意 | **學生公版必須真的能跑**，交付前在真平台從零實跑（K-VER-025） |
| 導覽 | 5–8 步 | 照上課順序，步數多；**步驟節點**讓學生直達任何一步 |

## 製程

1. **盤點素材**：逐字稿 → 抓出上課的實際順序與每一步「講師點了什麼、說了什麼」；截圖分類到步驟；示範用的提示詞、程式碼、公式原文收齊。逐字稿與截圖裡的真實人名、連結、信箱一律換成虛構。
2. **列章節與步驟**：先寫 `CH` 與 `STEPS` 的清單（每步一句字幕＋最常卡在哪），還不寫畫面。步驟要細到「學生照字幕做得出來」。
3. **擬真畫面**：一個平台一個 renderer。標籤文字以**真平台當下的畫面**為準，不憑記憶；講師授課用的是哪個體系就畫哪個（不要混進別家平台）。
4. **學生公版**：程式碼、公式寫死在 `#kit`，模擬畫面直接讀同一份（`CODE_A = kit-a.textContent`），示範與成品不分岔。要學生換成自己的值的地方，佔位文字寫成「貼上你的○○」，並在步驟裡獨立一步講怎麼換。
5. **真平台實跑**（取得帳號主人同意）：照公版從零做一次，雜湊比對貼進去的就是公版那份；失敗就修公版並把原因寫成那步的「常見錯誤」；真平台的文字回頭修模擬畫面。測不到的部分在交付訊息明講。
6. **作者標示**：講師要求時加淡浮水印（不透明度約 .04–.05）、角落署名、頁尾智慧財產聲明；都不擋按鈕。只寫講師要的字樣（例如不加「原創教材」就不加）。
7. **驗證**：從第 0 步依序 `goto` 到最後一步零錯誤；檢查關鍵狀態（例如學生貼的公式算得出正確數字）；`validate_html.py` PASS；1440 桌機寬截圖逐章目視，看字幕、小卡、署名有沒有擋到按鈕。

## 骨架已接好的技法

- 章節分頁＋步驟節點直達；`goto(i)` 以 FAST 重播前面所有步驟保證狀態正確。
- 播放模式依字幕長度停留；可關自動換頁；→／右鍵兩段式加速；← 上一步；空白鍵播放／暫停。
- 真點擊畫面 → `userTook()` 切自由操作；導覽與自由操作共用 `ACT`。
- `#s=N` 深連結（含 hashchange），講義或投影片可直接連到某一步。
- 字幕＋常見錯誤小卡、學生公版一鍵複製（剪貼簿失敗會出聲）、靜態「怎麼看這份教學」。

## 已知坑

- **Apps Script 網頁應用程式裡 `getActiveSpreadsheet()` 是 null**，就算是從試算表開的綁定專案也一樣；學生公版一律 `openById`（K-SYNC-011）。
- 模擬器全綠不代表學生照做會成功：授權何時出現、選項真名、預設值都要在真平台抄（K-VER-025）。
- 內嵌瀏覽器讀不到系統剪貼簿、擋 `file://` 的中文長路徑：自動測試改用本機 http 伺服器；交付給學生時請他們用 Edge／Chrome 開。
- 平台會改版（例如 Gem 改名「技能」）：教材上註明畫面日期，課程重開前再對一次。
- 單檔含圖約 4–5 MB；郵件常擋 .html，給雲端連結或壓縮檔。

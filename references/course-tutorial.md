# 課程互動教學 HTML（軌道 A 的變體）

> 把一堂「操作型」課程做成學生帶回家也能自己重看、自己照做的單檔離線 HTML。
> 骨架：`assets/course-tutorial-template.html`（v2：章節介紹與小結、浮動說明卡、零件卡、⚠ 一定要）
> 完整實作（11 章 107 步、Gemini／Apps Script／試算表／AppSheet 擬真畫面）：說明在 `library/components/F-UI-034_課程互動教學HTML/說明.md`；程式碼只在本機軟體資料庫 F-UI-034（含講師署名，不隨技能公開）
> 版面規範：軟體資料庫 K-VIS-005。引擎源頭：F-UI-032（給委託方看的功能示範）

## 什麼時候用

- 使用者在準備**課程、講義、教學示範、上課操作步驟、工作坊**，而課程內容是「教別人在某個軟體或平台上一步一步做出東西」。
- 手上有：講課逐字稿、上課截圖、示範對話紀錄、要學生貼的程式碼或公式。
- 不適用：只要投影片（用簡報類技能）、現場即時互動投票（用 `deck-site-factory`）、給委託方看的軟體提案（用 `client-demo.md`／F-UI-032）。

## 版面與節奏（負責人 2026-10-25 核定，見 K-VIS-005）

1. **畫面優先**：示範畫面佔滿舞台。瀏覽器外框（分頁、網址列、書籤）只在示範擴充功能這類「瀏覽器本身就是主角」的章節出現；手機預覽只留在平台本來就有手機預覽的頁面。
2. **說明浮在畫面上**：半透明說明卡，避開這一步碰過的所有地方，沒擋到就不移動；避不開時先換寬而矮的卡，再把提醒與零件收成一行，最後才變半透明。不要底部字幕長條，因為圖在上、字在下，眼睛無法聚焦。
3. **組裝說明式零件**：用得到程式碼、公式、範本的那一步，說明卡出現「🧩 這一步的零件」可複製或下載；全部零件另有獨立的「範本與程式碼」頁，兩邊同一份。
4. **「⚠ 一定要」只有一種長相**：講師強調的事（貼上前清空、每次存檔、程式碼先執行一次、部署更新要按鉛筆並選新版本……）每一次出現都標，不只第一次；目標放大、停 1.6～2.6 秒。下拉選單用慢動作假下拉；程式碼只標那一行；生成的圖片放大置中停約 4 秒。
5. **章節有頭有尾**：章節介紹用大字寫章名、AI 知能、用途、這章會做哪幾步；本章小結列出每一步（可點回去重看）與「下一章」。自動播放停在小結。
6. **權限類選擇不給預設答案**：例如「誰可以存取」，說明各情況選什麼，示範選某一個時講為什麼。

## 製程

1. **盤點素材**：逐字稿 → 抓出上課的實際順序與每一步「講師點了什麼、說了什麼」；截圖分類到步驟；示範用的提示詞、程式碼、公式原文收齊。逐字稿與截圖裡的真實人名、連結、信箱一律換成虛構。
2. **抓講師強調處**：在逐字稿裡搜「一定要、記得、講三次、很重要、注意」，列成「逐字稿重點」表（重點 → 對應步驟 → 呈現方式），每一條都要對到一個 `must()` 或停頓。
3. **列章節與步驟**：先寫 `CH`、`CHINFO`（每章的 AI 知能與用途）、`STEPS`（每步一句字幕＋最常卡在哪）、`PARTS`（哪一步用哪個零件），還不寫畫面。步驟要細到「學生照字幕做得出來」。
4. **擬真畫面**：一個平台一個 renderer。標籤文字以**真平台當下的畫面**為準，不憑記憶；講師授課用的是哪個體系就畫哪個。
5. **學生公版**：程式碼、公式寫死在 `#kit`，模擬畫面與零件卡讀同一份，示範與成品不分岔。要學生換成自己的值的地方，佔位文字寫成「貼上你的○○」，並在步驟裡獨立一步講怎麼換。
6. **真平台實跑**（取得帳號主人同意）：照公版從零做一次，雜湊比對貼進去的就是公版那份；失敗就修公版並把原因寫成那步的「常見錯誤」；真平台的文字回頭修模擬畫面。測不到的部分在交付訊息明講。
7. **作者標示**：講師要求時加淡浮水印（不透明度約 .04–.05）、角落署名、頁尾智慧財產聲明；都不擋按鈕。只寫講師要的字樣。
8. **驗證**：從第 0 步依序 `goto` 到最後一步零錯誤；檢查關鍵狀態；`validate_html.py` PASS；1440 桌機寬截圖逐章目視。
9. **冷測**：負責人的要求先寫成可驗的規格（每條附「怎麼驗」），再請另一個不知道施工過程的工作階段逐條實測、只測不修；不通過就修，再請它複測，直到全過。

## 骨架已接好的技法

- 章節分頁＋步驟節點直達；`goto(i)` 以 FAST 重播前面所有步驟保證狀態正確；`#s=N` 深連結。
- `CHINFO` → 執行時自動插入「章節介紹」與「本章小結」；小結的步驟按鈕不會切成自由操作；播放停在小結。
- 浮動說明卡 `placeCard()`／`clampCard()`；零件卡 `PARTS`；`must()` 統一標註。
- 播放依字幕長度停留；→／右鍵兩段式加速；← 上一步；空白鍵播放／暫停；真點擊畫面切自由操作。
- 只有本人按的「複製」才寫進系統剪貼簿（K-OPS-034）；靜態「怎麼看這份教學」與大綱在範本頁。

## 已知坑

- **Apps Script 網頁應用程式裡 `getActiveSpreadsheet()` 是 null**，就算是綁定專案也一樣；學生公版一律 `openById`（K-SYNC-011）。程式碼.gs 貼好要先「執行」一次，用到試算表的會在這時要授權。
- 模擬器全綠不代表學生照做會成功：授權何時出現、選項真名、預設值都要在真平台抄（K-VER-025）。
- **示範代按不可寫系統剪貼簿**：自動播放會一直蓋掉使用者自己複製的東西（K-OPS-034）。
- **整塊重畫的頁面不要每次重播淡入**：會一直更新的畫面（例如文字雲）會永遠半透明（K-RESIL-019）。
- **量版面要在前景**：隱藏的預覽窗格會暫停 `requestAnimationFrame` 與 `ResizeObserver`，背景量到的位置不準；改變尺寸時同步夾位，不要只靠這兩者（K-VER-026）。
- 共用樣式名稱要限定範圍：例如卡片的 `.wc` 撞到文字雲頁的 `wc`，整頁變淡。
- 內嵌瀏覽器擋 `file://` 的中文長路徑：自動測試改用本機 http 伺服器；交付給學生時請他們用 Edge／Chrome 開。
- 平台會改版（例如 Gem 改名「技能」）：教材上註明畫面日期，課程重開前再對一次。
- 單檔含圖約 4–5 MB；郵件常擋 .html，給雲端連結或壓縮檔。

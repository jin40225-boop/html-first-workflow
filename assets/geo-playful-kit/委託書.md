# 委託：「幾何活潑」萬用美術元件＋UI 介面套組 v1

你要做一套**可以一直重複使用**的設計套組：以後開發任何軟體、網站、簡報、表單工具時，直接從這裡拿，不必每次從頭畫。
風格已經定案，就是附上的參考圖（一張風格提案板）——**現代扁平幾何**：圓形、膠囊、半圓組合；乾淨飽滿的色塊；可愛的簡化人物（圓臉、腮紅、簡單五官）；點綴小圓點、波浪線、短促的「閃光三條線」。

這是**通用套組**：不屬於任何單一專案。檔案、說明、圖片裡**不得出現任何真實機構名、專案名、人名**。

## 一、配色（全套統一）
| 名稱 | 色碼 | 用途 |
|---|---|---|
| 珊瑚紅 coral | #FF6B6B | 強調、警示、重要 |
| 薄荷綠 mint | #1FBFA8 | 成功、完成、確認 |
| 陽光黃 sun | #FFC24B | 提醒、進行中、新增 |
| 晴空藍 sky | #3DA5F5 | 資訊、連結、主要動作 |
| 薰衣草紫 lavender | #A77BEA | 特殊、標記、督導／管理 |
| 墨棕 ink | #2D251A | 線條、文字 |
| 奶油白 cream | #FFF9F2 | 背景 |
每色再推一個淺色（背景用，約 12% 濃度）與一個深色（文字用，對比 ≥ 4.5:1），寫進 tokens.css。

## 二、硬規則
1. **所有圖都用你內建的 `image_gen` 畫**。禁止用 Pillow／SVG／程式「畫」圖形。程式只准：去背、裁切、切格、縮放、改色、壓縮、排字、產生 manifest。
2. **為了風格一致與省額度，用「拼圖」生成**：一次生成一張 4×4（或 3×3）等距格子的圖，每格一個主體、格與格之間大量留白、純色可去背的底；再用程式等分切開、去背、各自置中存檔。原始拼圖保留在 `_sheets/`。切壞的格子（主體被切到、兩個黏在一起）要重生那一張拼圖。
3. 圖裡**不要有任何文字、字母、數字、商標**。
4. 透明背景 PNG；去背後邊緣不要有色邊。圖示縮到 32×32 仍要認得出來（輪廓簡單、色塊大）。
5. PNG 要壓縮（量化到 256 色以內，看起來不能有明顯色階）。整個套組總大小目標 ≤ 15 MB。
6. 人物是可愛的卡通角色，不像任何真實人物；膚色、髮型、年齡、性別要多元。

## 三、要做的東西

### 1. icons/ — 通用圖示 96 個（6 張 4×4 拼圖），每個存 256×256
分 6 組，每組一張拼圖：
- **導覽與系統**：首頁、搜尋、設定齒輪、選單、使用者、團隊、通知鈴、說明問號、資訊 i、登出門、鎖、鑰匙、盾牌、眼睛、重新整理、篩選漏斗
- **檔案與資料**：資料夾、文件、上傳、下載、列印、匯出、匯入、試算表格子、資料庫、雲端、連結、迴紋針、封存箱、垃圾桶、複製、剪貼簿
- **動作與狀態**：新增加號、編輯鉛筆、勾勾完成、叉叉關閉、警告三角、錯誤驚嘆號、儲存磁片、暫存時鐘、同步雙箭頭、排序、拖曳把手、展開、收合、星星、愛心、旗子
- **溝通與時間**：對話氣泡、雙對話氣泡、信封、電話、視訊、麥克風、公告大聲公、日曆、時鐘、鬧鐘、沙漏、行事曆勾、地圖釘、地圖、路線、車子
- **人與服務**：家庭、長者、兒童、輪椅使用者、手牽手、握手、愛心手、房子、學校、醫療箱（不要用紅十字）、藥丸、餐點、輔具（拐杖）、志工背心、勳章、禮物
- **工作與分析**：長條圖、圓餅圖、折線圖、表格、清單、看板欄、目標靶心、獎盃、燈泡、火箭、拼圖、扳手、AI 閃光、機器人、問卷板、簽名筆

### 2. characters/ — 人物角色 16 個（2 張 3×3 拼圖，各取 8），每個存 512×512
同一組「角色家族」，比例、線條一致：工作者（拿平板）、主管（拿板夾）、長者（拄拐杖）、孩子、輪椅使用者、照顧者（推輪椅）、家長牽孩子、志工；以及表情動作：揮手打招呼、比讚、思考（手托下巴）、慶祝（雙手舉高＋彩帶）、看筆電工作、指向右邊（介紹用）、困惑（問號）、睡覺（Zzz 用圖形表示）。

### 3. spots/ — 情境插畫 12 張，每張單獨生成，存 800×600
空白（還沒有資料）、找不到結果、成功完成（彩帶）、出錯了（打結的線）、沒有網路、載入／等待（沙漏與小人）、歡迎／第一次使用、找不到頁面（迷路的地圖）、沒有權限（上鎖的門）、全部處理完（空的收件匣＋小花）、維護中（扳手與齒輪）、資料同步中（兩台電腦與雙箭頭）。

### 4. decor/ — 裝飾元素 24 個（2 張 4×4 拼圖，各取 12），存 256×256
圓點群、波浪線、半圓、膠囊、閃光三條線、星芒、彩帶碎片、圓角三角、弧線、小圓環、雲朵、葉子、愛心泡泡、對話框形狀、箭頭塗鴉、圓形印章框、斑點 blob ×4 種、角落花邊 ×2、分隔線 ×2。

### 5. markers/ — 標記與徽章
- `marker_{coral,mint,sun,sky,lavender}.png`（160×120）：從卡片外框頂端探出的**圓角對話框形小標籤**，中央留白色圓形空位（程式放數字或圖示）。只生成珊瑚紅一張，其他四色用程式改色，形狀必須完全一致。
- `badge_*.png`（一張 3×3 拼圖切出，存 256×256）：新、熱門、完成、待處理、重要、鎖定、草稿、置頂、已讀——**用圖形表達，不要文字**（例如完成＝綠圓章＋勾、置頂＝圖釘）。

### 6. backgrounds/
- `banner_blank_{left,right}.png`（1600×240）：橫幅底圖，插畫在左（或右）約 40%、其餘留白給程式排字；插畫內容＝角色家族中 2–3 人＋幾何小房子、樹、圓點波浪。
- `hero_blank.png`（1440×600）：登入／首頁大圖底，插畫在右半。
- `pattern_tile.png`（512×512）：**可無縫拼接**的淡色裝飾底紋（圓點、波浪、小星），整體很淡、不搶字。
- `card_corner_{a,b}.png`（256×256）：卡片角落裝飾。

### 7. ui/ — UI 介面套組（程式碼，這部分你直接寫）
- `tokens.css`：CSS 變數——色票（含淺色、深色）、圓角（8／12／16／999）、陰影、間距、字級（以 `"Microsoft JhengHei","Noto Sans TC"` 為主）、深色模式（`@media (prefers-color-scheme: dark)` 與 `[data-theme="dark"]` 都要）。
- `components.css`：只用 tokens 的元件樣式——按鈕（主要／次要／危險／幽靈／大小三種）、chip 篩選、分段切換、輸入框、**可填式下拉（下拉＋自己打字）**、勾選與開關、卡片（含「特殊標記」狀態：外框整圈換色＋頂端 marker）、徽章、標籤、分頁籤、表格、提示 toast、空白狀態區塊（配 spots 圖）、進度條、**能量條**（一人一列：現有＝實色、新增＝陽光黃、轉出＝斜紋、平均＝虛線）、頭像、統計數字卡、時間軸、步驟條、對話串（我方右／對方左）。
- `echarts-theme.js`：ECharts 主題（`echarts.registerTheme('geo-playful', …)`），用本套配色、圓角柱、柔和格線。
- `showcase.html`：單頁展示——每個元件的實際樣子＋所有圖片分類總覽（用相對路徑引用本套組圖片）、可切深淺色。要能直接用瀏覽器打開。不要連任何外部網址。

### 8. 說明與索引
- `manifest.json`：每個檔案一筆 `{ "file", "group", "name_zh", "use_zh", "size", "keywords" }`，讓 AI 能用關鍵字找素材。
- `README.md`（繁體中文）：這套是什麼、配色表、資料夾說明、**「我要做 X → 用哪個」對照表**、怎麼在新專案引用（複製哪些檔、怎麼在 HTML 內嵌成 data URI 做單檔離線）、怎麼產生新色或新圖示（沿用本委託書的拼圖做法與風格描述，附一段可直接貼給 image_gen 的「風格提示詞」）。
- `回覆.md`：每張拼圖／插畫的 image_gen 提示詞、重生了哪些、最後的總大小。

## 四、交付檢查（你自己做，不用等人驗收）
1. manifest.json 列的每個檔案都存在、尺寸對。
2. 把全部 icons 縮成 32×32 排一張對照圖 `_check/icons_32.png`，自己看一次認不認得出來、風格是否一致。
3. 五個 marker 形狀一致、只差顏色。
4. showcase.html 用瀏覽器打開沒有錯誤、圖片都載得到。
5. 全文搜尋，確定沒有任何真實機構名、專案名、人名。
